# DNF Market Analyst — 던파 라이브 마켓 애널리스트

기존 던파 시세 서비스가 "지금 얼마인지"를 보여주는 조회 도구라면, 본 시스템은
**"왜 움직였고, 무엇을 주목해야 하는지"를 해석해 데일리 브리핑으로 만드는 분석 시스템**이다.

던전앤파이터 경매장 시세를 매일 자동 수집하고, 이상 변동을 탐지하면 AI가 원인 가설을
근거와 함께 해석해 브리핑을 자동 발행한다.

## 아키텍처

- **수집**: GitHub Actions cron이 하루 3회(KST 09/15/03시) 추적 품목 31종의
  등록가·판매 완료 데이터를 수집해 `data/snapshots/`에 축적
- **집계**: 스냅샷 → `data/timeseries.json` 시계열 병합 (슬롯 중복 방지)
- **분석**: 규칙 기반 이상 탐지 → 이상 항목만 AI 맥락 해석 → 데일리 브리핑 (Phase 2)
- **대시보드**: React 정적 대시보드, Actions 데이터 커밋 → Vercel 자동 재배포 (Phase 3)

## 데이터 정책

- **비상업 개인 포트폴리오**이며 네오플과 무관한 비공식 팬메이드 프로젝트입니다
- 데이터 출처: **Neople 오픈 API 서비스** (https://developers.neople.co.kr)
- 원본 API 응답을 저장하지 않고, 분석에 필요한 **최소 집계 필드만 저장**합니다
  (최저·평균 단가, 매물 수, 24시간 판매 수)
- API 호출 절제 설계: 하루 3회 × 품목당 2호출, 호출 간 대기, 재시도 1회 제한
- 수집 실패·결손일은 합성 데이터로 채우지 않고 공백으로 정직하게 표기합니다
- 던파 아트워크·로고는 사용하지 않으며, 아이템 아이콘은 API가 제공하는
  공식 이미지 URL만 사용합니다

## 추적 품목

시장 대표성 기준으로 31종을 큐레이션했다 (`config/items.json`).
후보 64종 전수를 경매장 실호출로 검증해 실매물이 존재하는 품목만 채택했으며,
선정 사유는 품목별로 문서화되어 있다 (`config/items.candidates.json`).
